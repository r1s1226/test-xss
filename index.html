Unvalidated postMessage → javascript: — PoC harness

Drives a target page whose message handler navigates to a URL taken from the message without validating the sender or the scheme. The target is passed as a parameter, so nothing target-specific lives in this repository.
Open the harness

How to point it at a target

  • Append &target=https://host/path/ to the poc.html URL — or type it into the field on the harness page.
  • Allow pop-ups; the harness opens the target and keeps sending the message every 100 ms.
  • The dialog appears inside the target window once the vulnerable view is mounted.
  • &p=steal switches to a payload that reads a redux session store through the React fiber tree; add &hook=https://… to forward what it reads.
Why a window handle is mandatory, and the usual post-login precondition: see README.md.
